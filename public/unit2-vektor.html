Notasi & Representasi
Vektor ditulis dengan huruf tebal (A) atau dengan tanda panah di atas (Ā). Vektor memiliki besar (magnitude) dan arah.
A = Aₓ î + Aᵧ ĵ + A_z k̂
|A| = √(Aₓ² + Aᵧ² + A_z²)
θ = arctan(Aᵧ / Aₓ) [perhatikan kuadran]
Penjumlahan & Pengurangan
A + B = (Aₓ+Bₓ)î + (Aᵧ+Bᵧ)ĵ + (A_z+B_z)k̂
|R| = √(Aₓ+Bₓ)² + (Aᵧ+Bᵧ)² [2D]
|R|² = |A|² + |B|² + 2|A||B|cos θ [aturan kosinus]
Perkalian Titik (Dot Product)
A · B = AₓBₓ + AᵧBᵧ + A_zB_z
A · B = |A||B| cos θ
Hasil berupa skalar. Jika A · B = 0 maka A ⊥ B.
Perkalian Silang (Cross Product)
A × B = (AᵧB_z − A_zBᵧ)î − (AₓB_z − A_zBₓ)ĵ + (AₓBᵧ − AᵧBₓ)k̂
|A × B| = |A||B| sin θ
Hasil berupa vektor (arah: aturan tangan kanan). Jika A × B = 0 maka A ∥ B.
